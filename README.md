# Live System Health Monitor

A real-time web-based System Health Monitoring dashboard built with Python, Flask, psutil, and Chart.js.

## Features
- Live CPU, RAM, Disk, and Battery tracking
- Real-time updating Chart.js line graph
- Threshold alerts (highlights in red above 80%)
- Top 5 memory-consuming processes table

## How to Run
1. Install dependencies:
   `pip install -r requirements.txt`
2. Run the app:
   `python app.py`
3. Open `http://127.0.0.1:5000` in your browser.
